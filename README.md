# Les Xu Vietnam Entry Advisory Site

Static Astro site for Les Xu's Vietnam entry and owner-independent operations advisory offer.

## Local Commands

```bash
npm install
npm run build
npm run check:site
```

`npm run check:source` runs without downloaded dependencies and verifies the expected routes, public name, CTA text, LinkedIn URL, and copied imagery exist in source.
